Cómo usar
Las AudioZones son regiones del mundo que reproducen audio automáticamente cuando el jugador entra en ellas.

Usá AudioZoneSystem.triggerOnOverlap('id', { onEnter, onExit }) para ejecutar código propio al entrar o salir.
Atenuación
Linear
Volumen decrece de forma uniforme con la distancia.
Quadratic
Caída más suave cerca del centro, más brusca en los bordes. Recomendado para música ambiental.
Logarithmic
Simula atenuación acústica real. Ideal para SFX posicionales.

Game Loop estable con dt Sin requestAnimationFrame + delta time, el movimiento depende del FPS del navegador. ✅ Hecho dt capped a 100ms, FPS cap 60Hz con corrección de drift, contador FPS en HUD (verde/amarillo/rojo).
Física 2D y Colisiones No hay hitboxes, gravedad, ni deteccion de solapamientos. ✅ Hecho Hitbox por objeto (hbOffX/Y/W/H), capas de colision (player/npc/wall/trigger/default), isSolid flag, debug overlay HB.
Sistema de Cámara El canvas era estático. Requería seguimiento, límites, parallax y zoom. ✅ Hecho Camera2D con smoothDamp (lerp 0.12), Camera2D.shake(t, intensity), setBounds(minX,minY,maxX,maxY) auto-init, parallaxLayers[] con tiling, setZoom() con ctx.scale. API global: Camera2D.shake/setBounds/setZoom/addParallaxLayer.
Input Manager Unificado Solo había atajos de editor. Faltaba mapeo para juego (teclado, gamepad, touch). ✅ Hecho InputManager con isAction(action), mapAction(action, ...codes) remappable + localStorage, Gamepad API (navigator.getGamepads, deadzone, D-pad, botones), touch virtual joystick con thumb drag, acciones lógicas (left/right/up/down/jump/action/run) desacopladas del código físico.
Gestor de Escenas Múltiples Solo existía Mapa Principal. Sin menus, load screens, ni transiciones entre niveles. ✅ Hecho SceneManager con load(), unload(), transition(fade/slide), persistData() entre escenas. Panel en solapa "Escenas".
Máquina de Estados del Juego No había diferencia entre Editor, Play, Pause, Debug, Menu. ✅ Hecho GameState Machine: EDITOR|PLAYING|PAUSED|DEBUG|MENU. Bloqueo UI editor, pausa real con P, debug con F3, resume seguro, overlay de pausa con menú.
Undo/Redo Real (Command Pattern) CommandHistory con execute()/undo() por objeto. Diff por propiedad, sin snapshot total. Soporta: agregar, eliminar, mover, redimensionar, cambiar props, tilemap fill/clear. ✅ Listo CmdAddObject, CmdRemoveObject, CmdMoveObject, CmdResizeObject, CmdSetProp, CmdBulkReplace. Debounce en inspector.
Depurador Visual (Debugger) Panel flotante con 4 tabs: Info, Watchers, Log, Perf. step() por frame, watchers con eval seguro, logNodeExecution(), toggle HB/FPS/LOG/VEL, sparkline FPS, vectores de velocidad. ✅ Listo F3=toggle, S=step frame, 4 tabs, watchers JS, logNodeExecution() global, FPS sparkline, vel vectors en canvas.
Plantillas de Sistemas Comunes TemplateManager con drag & drop: InventoryBasic, DialogueTree, SaveSystem, PlatformerKit. ✅ Listo Modal de plantillas integrado: 📦 InventoryBasic, 💬 DialogueTree, 💾 SaveSystem, 🎮 PlatformerKit. Inserción con un click en la escena activa.
Gestión Profesional de Assets IndexedDB persistencia entre sesiones, tags por asset, vista grid/list, preview modal con edición, SpritePacker (atlas PNG + JSON). ✅ Listo IDB auto-sync, tags con filtro chip, toggle grid/list, dblclick=preview+edición, SpritePacker: selección, preview atlas, export PNG+JSON.
